# magnet-wall — 磁吸索引墙

指针靠近时每张卡片按自己的距离衰减朝指针倾斜，离开后各自归位；滚轮在三个密度档位之间精确落位，两端夹住。

- 单文件：`index.html`（无构建、无依赖、无 CDN）
- 机制：**距离衰减倾斜** + **离散档位落位**
- 栈：DOM + CSS 变量 + rAF（rung 0 页面栈 / 不用任何动效库）

## 2 · 动效系统

### 阶梯层级

页面栈 rung 0（单文件、无构建）。动效栈停在 **rung 1.5**：用 rAF 手写，没有引入任何库——这个机制用库反而看不出它在做什么。要往上爬的唯一情形是同时需要物理关节或刚体，那时才值得动库。

### 机制清单

| 机制 | 触发 | 驱动 | 作用范围 |
|---|---|---|---|
| 距离衰减倾斜 | `pointermove` | rAF（每帧一次） | 整面墙，半径 R 内 |
| 档位落位 | `wheel` / 按钮点击 | 直接改 `data-step` | 三个离散值，无中间态 |

### 参数（实测值）

| 参数 | 紧凑 | 标准 | 舒展 |
|---|---|---|---|
| `--gap` | 8px | 16px | 28px |
| `--tile-min` | 150px | 190px | 250px |
| `--reach` 衰减半径 | 190px | 250px | 330px |
| `--lean` 最大位移 | 8px | 12px | 17px |
| `--tilt` 最大倾角 | 5deg | 8deg | 11deg |

其余：衰减曲线 `smoothstep = t²(3−2t)`；过渡 `260ms cubic-bezier(.2,.8,.2,1)`；滚轮冷却 220ms；倾斜缩放系数 `.035`。

### 减动效设计（是设计过的一版，不是"关掉"）

| 项 | 减少动效下的行为 |
|---|---|
| 倾斜 | 整体关闭（`transform: none !important`），指针事件短路，连变量都不写 |
| 档位切换 | 仍然可用，只是变成瞬时 |
| 页面内容 | 完整。墙是静态标记渲染的，所以拿到的是**一整页**而不是空页 |

## 4 · 可以照搬 / 不许照搬

### ✅ 可以照搬（机制层）

- **`data-step` + CSS 变量契约**：三个档位只改五个变量，别的什么都不动。任何"离散档位"都能套。
- **`.tile` 的 transform 表达式**：把 `--mx/--my/--lift` 三个数换成几何的那一行。这是 CSS 与 JS 之间唯一的接口。
- **静止坐标从 `offsetLeft/offsetTop` 取**：不受自身 transform 影响。理由见第 5 节。
- **滚轮边界放行**：`next` 越界时直接 `return`，不 `preventDefault`。
- **`--lift` 同时驱动位移和边框**：一个数喂两个通道，静帧也能看出磁场形状。

### ❌ 不许照搬（皮层）

- 全部颜色令牌、字号阶、圆角值——那是这个案例的皮肤。
- "索引墙"的排版与 12 个条目的文案。
- 三个档位的名字（紧凑/标准/舒展）。

**照搬的是推理，不是数值。** 例：`smoothstep` 该照搬的是"力要在半径边缘平滑归零"这条理由，而不是 `t²(3−2t)` 这个具体式子——线性衰减在边缘会有可见的"突然出现"，换成别的平滑函数同样成立。

## 5 · 踩过的坑

### ① 静止坐标绝不能从 `getBoundingClientRect()` 读

卡片自己被 `transform` 推着走。如果每帧用它**当前**的矩形去算到指针的距离，位移改变了矩形、矩形改变了距离、距离又改变位移——形成反馈回路，卡片会自己抖起来。

**取法**：`.wall { position: relative }` 让卡片成为 offsetParent，然后用 `wallRect.left + tile.offsetLeft + tile.offsetWidth / 2`。`offsetLeft` 是布局值，transform 碰不到它。

**暴露它的数**：归位后残差。用错取法时这个数不会收敛到 0。

### ② 滚轮做"两端夹住"时必须同时做"边界放行"

如果无脑 `preventDefault()` 再把档位夹到 `[0,2]`，那么指针恰好停在墙上时**整页就滚不动了**——一个隐形陷阱，而且看起来像页面卡死。

**做法**：先算 `next`，越界就 `return`（不拦截），让滚轮交还给页面。实测在最高档继续上滚，`scrollY` 正常到 300。

### ③ 这个副本缺少 `verify_case.py`

`cases/` 目录只有案例和 `AUTHORING.md`，原文引用的 `scripts/`（`measure_churn.py`、`measure_structure.py`、`verify_case.py`）与 `references/` 都不在。所以本案例的验证是另写的等价脚本，上面判据表的数字来自那一轮。

**这意味着**：以后新增案例时，"真实滚轮 + 真实 hover"这条底线需要自己保证，没有现成工具兜底。

### ④ 颜色混合里的 `calc` 百分比是可行的

`border-color: color-mix(in srgb, var(--accent) calc(var(--lift) * 100%), var(--line))` 一开始不确定 `calc` 里的百分比能不能接受一个无单位的自定义属性乘算。实测可行（边框确实从 `srgb(.851 .835 .788)` 变到 `srgb(.542 .202 .073)`），但这是一条**浏览器实现细节**，不是规范里的常识——换环境要复测。

## 6 · 改造方向

同一个机制指向别的页面：

| 目标 | 改什么 |
|---|---|
| **站内首页 bento 卡片组** | 把半径衰减换成"按卡片到指针的距离分层"，位移量调小（2–4px），避免和已有的 3D 倾斜叠加过度 |
| **归档页按月分组** | 组内条目一起倾斜：把距离算到**组**而不是单条，得到"整组被吸过来"的手感 |
| **评论区表情按钮** | 同一套衰减，半径收紧到 80–120px，位移 2–3px；按钮小，参数要重新量 |
| **任何"网格 + 指针"** | 直接复用 `--mx/--my/--lift` 三变量契约与 transform 表达式，只换几何和档位数值 |

**朝指针倾斜的符号约定**（`rotateX = −y`、`rotateY = +x`）与站内卡片倾斜一致，所以这两套动效可以互换位置而不会打架——改造时可以先借这个约定。
