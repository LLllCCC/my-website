指针移动 → 距离衰减倾斜 当前档位：标准

这个机制怎么工作

距离衰减
每张卡片读到指针的距离 d，先取 1 − d / 半径，再过一次 smoothstep（t²(3−2t)）。线性衰减在半径边缘有明显的"突然出现"， smoothstep 让力在两端都趋近于零，所以磁场没有可见的边界。
静止坐标
几何一律从 offsetLeft / offsetTop 读，不用 getBoundingClientRect()。因为卡片自己被 transform 推着走， 用变换后的矩形算距离会形成反馈回路，卡片会自己抖起来。
倾角约定
rotateX = −y、rotateY = +x，和站内卡片倾斜是同一套符号。 这样一来磁吸和倾斜不会打架，改造时可以直接互换。
档位落位
档位只有 0 / 1 / 2 三个整数，不存在中间值——每次切换都精确落在 定义好的几何上。到边界时不再拦截滚轮，页面继续正常滚动， 所以这一块不会变成滚不出去的陷阱。
减动效
开启"减少动效"后，倾斜整体关闭，档位按钮仍然可用、切换变成瞬时。 墙是静态标记，所以关闭动效拿到的是一整页，不是一个空页。
可以照搬的部分
档位变量契约、transform 表达式、静止坐标的取法、滚轮边界放行。 颜色、字号和这套索引墙的排版属于皮层，照搬是错的—— 该照搬的是上面这些推理。

单文件，无构建，无依赖。直接打开或本地起服务都可以。
