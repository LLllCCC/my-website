这是改造 Obsidian 系列的第三篇。前两篇分别处理了文件结构和同步，这一篇只讲一件事：把首页做成一个真正愿意每天打开的面板。

先拆掉默认首页

默认的空白笔记没有信息密度。我把它换成一个 dashboard，用 Dataview 拉取任务、日记与阅读记录，再用 CSS snippet 重排成四张时间环。

```dataview
TABLE file.mtime AS "更新", tags AS "标签"
FROM "10-Daily"
SORT file.mtime DESC
LIMIT 7
```

时间环不是插件，而是四段 conic-gradient。百分比通过 inline style 注入，这样不用引入任何图表库，文件依然是一个纯 Markdown 库。

时间环的数据从哪来

今天、本周、本月、今年，四种粒度的数据分别来自日记、周记和年度目标。为了避免每次打开都重算，我写了一个小脚本，把结果缓存到 frontmatter。

不要把面板做成第二个待办清单。它应该回答“我现在在哪”，而不是“我还有多少事没做”。

人生余额与番茄钟

“人生余额”是一个略显残酷的进度条：按 80 岁计算，现在走到哪里。它放在首页底部，提醒自己时间有限，但不制造焦虑。

右侧的番茄钟是一个独立插件。它和 dashboard 共享同一个专注记录文件，所以统计能自动汇总。关键是不要让它们各自维护一份数据。

一个坑：Obsidian 的嵌套标签在 Dataview 里会被拆成多行，统计前先统一成一级标签，否则时间环的百分比会重复计算。

下一步

下一步想把阅读记录也接进来，按主题做一张年度热力图。但在这之前，先让这个面板安静地用一周，看看哪些数字真的会被看。
